# f1-dashboard


## Description

Live F1 streamlit dashboard for viewing current and historical season stats, championship standings, and records. Data automatically refreshes with GitHub Actions, and pulls from the fastf1 package. 

View it [here](https://the-stopwatch-never-lies-f1.streamlit.app/)
